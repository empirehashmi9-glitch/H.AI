One-time RDP setup

Remote Desktop on karen

Settings → System → Remote Desktop → On. Windows Pro/Enterprise chahiye. Ya admin PowerShell me:

Set-ItemProperty -Path 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 0; Enable-NetFirewallRule -DisplayGroup 'Remote Desktop'

Account par password

RDP password ke bagair sign-in nahi karta. Microsoft account ho to email + Microsoft password (PIN nahi).

App me PC add karen

+ → Add PC → address me — → username + password. Poora desktop phone par.

Bahar se? Tailscale lagayen

Dono devices par Tailscale install karen. Public port forward ki zaroorat nahi, aur beacon bhi private rehta hai.

Detected tools

RDP ke ilawa RustDesk ya Chrome Remote Desktop bhi chal jayega — signed tools only.

Security

  • Pairing code har API request verify karta hai; 6 ghalat tries par 5 minute lock.
  • Code sirf is phone me (localStorage) save hota hai, PC par nahi.
  • Screen/input Windows RDP se — koi unsigned capture script nahi.
  • Sirf apni machine ke liye. Doosron ka PC access karna allowed nahi.
